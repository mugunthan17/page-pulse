PagePulse is a full-stack web application for analyzing and scoring website performance, SEO, accessibility, and security.

## Project Structure

- PagePulse-BackEnd: Node.js/Express backend for page analysis and scoring
- PagePulse-FrontEnd: React/Vite frontend for the user experience

## Features

- Analyze webpage performance and SEO data
- Generate audit reports with actionable insights
- Display structured metrics for content, performance, and security

## Getting Started

### Backend

1. Navigate to the backend folder:
   ```bash
   cd PagePulse-BackEnd
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```

### Frontend

1. Navigate to the frontend folder:
   ```bash
   cd PagePulse-FrontEnd
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Tech Stack

- Frontend: React, Vite
- Backend: Node.js, Express
- Styling: Tailwind CSS
